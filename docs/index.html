HACKGPT / 01

Start here

Install the signed APK, find the main controls, and send a first message.

Toolbar

  1. First gear opens provider Settings.
  2. List icon opens the model picker.
  3. Clock opens Chat history.
  4. Half-filled circle opens Appearance.
  5. Second gear opens Codex settings.
  6. Badge shows available balance or quota.
  7. Plus starts a new chat. Hold it for five seconds for creator credits.

First message

  1. On Android 8.0 or newer, open the signed APK and confirm installation. Allow installs from your browser or file manager if asked.
  2. Open Select model and choose Demo → Beam 1.0 Free.
  3. Type a message. Tap the pulsing marker above the field if the circle is hidden, then tap the circle to send.

Install the signed update over your existing app to keep your chats. The pulsing up-arrow in the toolbar appears when a newer release is available. Tap it, download the APK, and open it to update.

HACKGPT / 02

Connect a provider

The plug loads models. The disk saves your provider and model choices.

  1. Tap the first gear. Tap a saved card to edit it, or use + inside Settings for a new provider.
  2. Choose OpenRouter, OpenAI, Gemini, or Custom (OpenAI-compatible). Enter a display name in the left field.
  3. Check the HTTPS base URL. NaraRouter uses https://router.bynara.id/v1.
  4. Enter the provider key. When editing, leave the field empty to reuse the saved key.
  5. Tap the plug to connect.
  6. Filter and check the models you want in the picker.
  7. Tap the disk to save. Open the model picker to use your selections.
  8. Tap play to test checked models. Test requests may incur provider charges.

In the newer test APK the grid shows up to three complete rows. Swipe inside it for more. Swipe a card left to remove it after confirmation.

HACKGPT / 03

Pick, inspect, and retest

The picker groups checked models by provider.

  1. Search by model name or ID. Tap a row and check the model above the message field.
  2. Hold a model for available context size, output limits, pricing, and input or image support.
  3. A red strikethrough and timestamp show a failed test. Tap that row to inspect it again.
  4. Tap play to retest. Success clears the failed marker.

Top-right badge

Kenari shows available rupiah. Routr shows credits for the active model. Tap that badge to switch between compact and exact counts. Demo shows FREE. The newer test APK adds NaraRouter’s available rupiah credits when returned by the account.

HACKGPT / 04

Send and swipe

The floating circle sends messages and has four directional shortcuts.

Regular mode

Tap the pulsing marker to reveal the circle. Tap the circle to send. Enter adds a line.

Enter-to-Send

Enable it in Appearance. Enter sends and Shift+Enter adds a line when supported. Tap the chat twice and hold the third touch to reveal the action circle.

Practice a swipe

Drag the dot or tap an arrow.

Open the Android file picker.

Save the open conversation as Markdown.

Select the text in the draft.

Open the draft-clear confirmation.

Hold the marker and drag sideways to move the circle. Release near the middle to snap it to center. Drag either top corner of the composer vertically to resize it. The circle fades after about two idle seconds. Use the square above the field to stop a regular reply.

HACKGPT / 05

History and appearance

The clock opens saved chats. The half-filled circle opens Appearance.

History

  1. Search by title, message, or attachment name. Tap to reopen. Swipe right to rename or left to delete.
  2. Hold a row to select it. Use the checkbox for all visible results.
  3. Tap download to save a ZIP of Markdown files. To export one chat, swipe down on the composer circle.
  4. Use the delete icon for selected chats and confirm.

Appearance

  1. Choose Dark or Light.
  2. Tap the return arrow to toggle Enter-to-Send.
  3. Tap the corner icon to toggle Full screen.
  4. Drag the font-size slider. Tap outside to close.

Markdown filenames start with the chat’s UTC timestamp. Exports preserve formatting, diagram source, attachment names, and available response details.

HACKGPT / 06

Visual replies and model handoff

Captured from the running browser preview with sample messages.

Attachments and images

Swipe up to attach files. Choose a compatible model. Limits are 256 KB per text file, 5 MB per image or PDF, and 6 MB total.

Swipe inside wide tables or code blocks. Tap bold underlined links to open the browser. Ask for charts or diagrams in plain language.

For an image result, tap the arrow to save. Double-tap or hold to preview. Pinch to zoom, twist to rotate in 90° steps, and tap outside to close. Available dimensions, file size, time, and usage appear below.

Switch models

Pick another model. Slide from full history through ¾, ½, and ¼ summaries to a fresh start. Fresh start sends only your next prompt.

At a summary level, choose the previous or incoming model and tap play. Review the summary of both sides of the conversation. Triple-tap the field to edit. Include the latest generated image when offered.

HACKGPT / 07

Connect to Codex on your PC

Continue working on a PC project from the Android composer.

  1. Start Codex App Server on the PC and publish it privately through Tailscale Serve. Join the same private network on both devices. Tap the Codex gear or tap the chat seven times. Paste the private wss:// URL.
  2. Enter the token from the PC setup. Leave it blank to reuse a saved token for the same URL.
  3. Enter the full project folder path on the PC.
  4. Tap Connect. The circled folder opens threads, circled plus creates a thread, arrows refresh the list, and the power icon disconnects.

Send from the main composer and review approval cards. Tap the square inside the centered circle to stop a turn. Tap the pulsing X to exit, then seven-tap to return.

HACKGPT / 08

Factory.ai and troubleshooting

Factory.ai and the NaraRouter badge require the newer test APK.

Factory.ai

Open Settings → Factory.ai. Add your API key and select Environment or Computer. Enter the target ID, tap Connect, then Save. Select Droid and send a text prompt. Follow-ups in the same chat can resume the Factory session.

Get a Factory API key · Find a Factory target

  1. No models load. Check the API key, HTTPS base URL, and account access.
  2. Model missing. Check it in Settings, save, and clear the model search.
  3. Image request fails. Try a short text prompt with a model that generates images.
  4. NaraRouter badge missing. Select a model saved under https://router.bynara.id/v1 and confirm account balance access.
  5. Codex disconnected. Check the PC and phone are online in Tailscale. Confirm the App Server, private URL, and token.
  6. No Codex threads. Check the full project path. Refresh or start a new thread.
  7. Factory times out. Check the existing Factory session before sending the prompt again.
  8. Update fails. Use an APK signed with the original release key to keep local app data.
